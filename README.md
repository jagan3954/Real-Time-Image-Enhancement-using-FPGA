

# 🚀 Real-Time Image Enhancement on PYNQ-Z2

This project implements a real-time, hardware-accelerated image processing pipeline on the **PYNQ-Z2 (Zynq-7020)** FPGA. It leverages an AXI4-Stream architecture to fetch video frames from memory, process them through a custom hardware IP, and output the enhanced video directly to an HDMI monitor at **480p (640x480)**.

## 🛠️ Hardware & Software Requirements
* **Board:** PYNQ-Z2 (Zynq-7020)
* **Output:** HDMI Monitor (Native 480p support recommended)
* **Software:** Xilinx Vivado (2020.1 or newer recommended)
* **Environment:** Jupyter Notebooks running on the PYNQ Linux image

## 📐 System Architecture

The hardware block design (`loop_again_main.bd`) relies on a robust AXI4-Stream video pipeline:

1. **Processing System (PS7):** Manages control signals and Jupyter Python environment.
2. **AXI VDMA (Video Direct Memory Access):** Reads uncompressed frame data from DDR memory and streams it via AXI4-Stream.
3. **Custom Image Processing IP:** Performs real-time pixel operations (e.g., filtering, enhancement) via AXI-Stream interfaces.
4. **AXI-Stream Subset Converter:** Remaps 32-bit RGBA stream data to the 24-bit RGB format required by the HDMI standard.
5. **AXI4-Stream to Video Out:** Synchronizes the AXI data with the display timing signals.
6. **Video Timing Controller (VTC):** Generates 480p timing syncs (HSYNC, VSYNC, VDE).
7. **RGB2DVI (Digilent):** Serializes the parallel RGB data into HDMI-compatible TMDS signals.

### ⏱️ Clocking Scheme
The design relies on a dual-clock architecture generated by a Clocking Wizard:
* **Pixel Clock (`clk_out1`):** `25.2 MHz` (Drives the VDMA, VTC, and Video Out)
* **Serial Clock (`clk_out2`):** `126.0 MHz` (Drives the TMDS serialization inside the RGB2DVI block, maintaining a strict 5:1 ratio).

## 🚀 Quick Start Guide

### 1. Hardware Setup
1. Clone this repository.
2. Open the Vivado project (`image_me.xpr`).
3. Generate the Bitstream (`.bit`) and Export the Hardware (`.hwh`).
4. Copy both files to your PYNQ-Z2 board (e.g., via Samba or Jupyter upload).

### 2. Python Initialization (Jupyter Notebook)
Use the following Python snippet to load the overlay, kickstart the VDMA, and enable the Video Timing Controller.

```python

# Set up your frame buffer and trigger the VDMA here...
from pynq import Overlay, MMIO, allocate
import numpy as np
import cv2
import time
import matplotlib.pyplot as plt

class HardwareVisionPipeline:
    def __init__(self, bitstream_path):
        # 1. Load the perfectly-timed Hardware!
        print("Loading Bitstream...")
        self.overlay = Overlay(bitstream_path) //use │   ├── fix.bit, fix.hwh from the Bitstream folder

        
        # 2. Setup AXI Connections
        self.ctrl = MMIO(self.overlay.ip_dict['img_pro_top_loop_bac_0']['phys_addr'], 0x100)
        self.vdma = MMIO(self.overlay.ip_dict['axi_vdma_0']['phys_addr'], 0x10000)
        
        # 3. Memory Allocation
        self.width, self.height = 640, 480
        self.stride = self.width * 4
        self.in_buf = allocate(shape=(self.height, self.width, 4), dtype=np.uint8)
        self.out_buf = allocate(shape=(self.height, self.width, 4), dtype=np.uint8)
        print("Hardware ready for full pipeline execution!")

    def set_parameters(self, brightness, min_val, max_val):
        # Calculate scale factor for the contrast module
        diff = (max_val - min_val) if (max_val > min_val) else 1
        scale_factor = int((255 / diff) * 256) 
        
        # Send to FPGA
        self.ctrl.write(0x00, int(brightness))
        self.ctrl.write(0x04, int(min_val))
        self.ctrl.write(0x08, int(scale_factor))
        print(f"HW Updated -> Brightness: {brightness}, Min: {min_val}, Max: {max_val}")

    def process_image(self, image_path):
        # --- 1. PREPARE INPUT ---
        img = cv2.imread(image_path)
        if img is None:
            print("Error: Image not found!")
            return None
            
        img = cv2.resize(img, (self.width, self.height))
        self.in_buf[:] = cv2.cvtColor(img, cv2.COLOR_BGR2RGBA)
        self.in_buf.flush()
        
        # --- 2. START THE FPGA PIPELINE ---
        # Reset VDMA
        self.vdma.write(0x00, 0x4) 
        self.vdma.write(0x30, 0x4) 
        time.sleep(0.02)
        
        # Start VDMA
        self.vdma.write(0x00, 0x01)
        self.vdma.write(0x30, 0x01)
        self.vdma.write(0x5C, self.in_buf.physical_address)
        self.vdma.write(0xAC, self.out_buf.physical_address)
        self.vdma.write(0x54, self.stride)
        self.vdma.write(0x58, self.stride)
        self.vdma.write(0xA4, self.stride)
        self.vdma.write(0xA8, self.stride)
        
        # Trigger the transfer
        self.vdma.write(0xA0, self.height)
        self.vdma.write(0x50, self.height)
        
        # --- 3. WAIT FOR COMPLETION ---
        # The FPGA is now running Grayscale -> Noise -> Brightness -> Contrast -> Sobel
        start_time = time.time()
        while not (self.vdma.read(0x34) & 0x1000):
            if time.time() - start_time > 2.0:
                print("VDMA Timeout!")
                return None
            
        self.out_buf.invalidate()
        print("Pipeline execution complete!")
        return cv2.cvtColor(self.out_buf, cv2.COLOR_RGBA2RGB)

# ==========================================
# EXECUTE THE SCRIPT
# ==========================================

# 1. Initialize
# (Make sure this points to your NEW perfectly-timed bitstream!)
pipeline = HardwareVisionPipeline("Bitstreamfiles/fixed_slack.bit")  

# 2. Set Parameters to help Sobel pop
pipeline.set_parameters(brightness=0, min_val=40, max_val=200)

# 3. Run the Image
# (Try this on your noisy cat image!)
result_img = pipeline.process_image("test2.jpeg")

# 4. Display the results
if result_img is not None:
    orig_img = cv2.imread("test2.jpeg")
    orig_img = cv2.cvtColor(orig_img, cv2.COLOR_BGR2RGB)
    
    fig, axes = plt.subplots(1, 2, figsize=(15, 6))
    
    axes[0].imshow(orig_img)
    axes[0].set_title("1. Original Input")
    axes[0].axis('off')
    
    axes[1].imshow(result_img)
    axes[1].set_title("5. Final Output (HW Sobel Edges)")
    axes[1].axis('off')
    
    plt.tight_layout()
```
